THE IDEA

Learn by seeing how it works.

This collection starts with a small question, makes the math visible, then lets you experiment with the code. You’ll move from fitting a line and following a gradient to testing ideas, finding patterns, and making simple decisions with data.

Each project includes a notebook with explanations and visualizations, plus a standalone Python script. Start anywhere, change the examples, and see what happens.
